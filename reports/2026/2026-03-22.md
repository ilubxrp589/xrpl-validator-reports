## Engineering changes

- **feat(viewer): auto peer discovery from TMEndpoints** (`506923e`, xrpl-validator)
  When a connected peer sends TMEndpoints, we automatically connect to new peers we haven't seen before. Filters out local/IPv6 addrs. Max 15 concurrent peer connections. Peers at hop count <= 1 only.
- **feat(viewer): live peer count with connected/discovered display** (`861112a`, xrpl-validator)
  /api/peers endpoint returns connected count, known peers, and max. Header shows PEERS 2/5 (connected/discovered) updating every 5s. Peer panel shows all discovered peers sorted alphabetically.
- **fix: sled storage for sync, peer identity verification, consensus wiring** (`3a37944`, xrpl-validator)
  Three incomplete items from assessment, now fixed: 1. Sync writes to sled DB alongside JSONL - sled::Batch for atomic page writes - Binary key/value storage (not hex text) - DB at /mnt/xrpl-data/sync/state.sled/
- **fix(viewer): neural network consensus viz with tab-switch fix** (`24703dd`, xrpl-validator)
  Restore neural network visualization as the consensus page. When switching tabs and returning, accumulated pulses are now flushed (detects >0.5s frame gap) to prevent lag burst. SSE events skip queuing visual effects while tab is hidden.
- **feat(ledger): transaction application engine with testnet verification** (`c64f330`, xrpl-validator)
  Complete transaction engine implementing the XRPL ledger close pipeline: - Keylet system: deterministic 256-bit state keys (3 mainnet-verified) - Sandbox: transactional overlay with snapshot/rollback for tec safety - Transactor trait: preflight → preclaim → apply_common → do_apply - Payment: XRP direct payments with account creation, reserve checks - OfferCreate/Cancel: DEX order placement with crossing framework - …
- **feat(viewer): engine dashboard, tx-type visuals, regression tests** (`6818946`, xrpl-validator)
  Metrics page: - XRP fee burn counter with sparkline (total + per-round) - Transaction type breakdown bars (color-coded by type) - Engine coverage card (supported vs unsupported percentage)
- **feat(ledger): complete tx type coverage + engine dashboard + audited** (`ebaa41e`, xrpl-validator)
  Transaction types (33 total, up from 6): - Added: Escrow (Create/Finish/Cancel), Check (Create/Cash/Cancel), PayChannel (Create/Claim/Fund), NFToken (Mint/Burn/CreateOffer/ AcceptOffer/CancelOffer), AMM (Create/Deposit/Withdraw/Vote/Bid/ Delete), SetRegularKey, SignerListSet, DepositPreauth, Clawback, Credential (Create/Delete/Accept)
- **feat: live engine, peer network page, dashboard redesign, identity** (`343ae01`, xrpl-validator)
  Live Engine: - Opens sled DB (18.7M+ entries) and applies transactions to real mainnet state in real-time - Decodes binary XRPL objects, deducts fees, writes back to sled - Tracks applied/failed/total stats exposed via /api/engine - XRPL_NO_ENGINE env var disables engine while sync runs
