  Counters parallel to live_diverged_by_type: - live_apply_silent_diverged: total - silent_diverged_by_pair: "{tx_type}/{our_ter}->{net_ter}" → count - silent_diverged_samples: rolling last-50 buffer for the dashboard
- **fix(ffi): set header.closeTime so view.parentCloseTime() isn't always epoch** (`9af0b0a`, xrpl-validator)
  OpenView's open_ledger constructor (OpenView.cpp:105) sets info_.parentCloseTime = base_->info().closeTime — it READS base.closeTime, not base.parentCloseTime. We were setting only header.parentCloseTime; header.closeTime defaulted to 0. Result: view.parentCloseTime() returned the epoch for every tx, and every libxrpl check that consults it broke in a category-specific way: - OfferCreate's hasExpired(view, …
- **feat(ffi): mutation-list divergence detection (BF6C928F class)** (`f0de666`, xrpl-validator)
  Third detection lane after regular and silent: same TER on both sides, different sets of state mutations. Catches cases where our shim and network agreed the tx applied successfully (or hit the same tec*) but the AffectedNodes the tx ended up touching differ.
