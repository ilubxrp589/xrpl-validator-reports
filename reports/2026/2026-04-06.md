## Engineering changes

- **feat(ffi): re-enable DB snapshot in steady state + filter pseudo-txs** (`35e01f5`, xrpl-validator)
  Two improvements to FFI verification accuracy and performance: 1. OwnedSnapshot enabled when DB is caught up (steady state): - Check: last_synced within 2 ledgers of process_seq - If steady → take OwnedSnapshot BEFORE process_ledger writes, use OverlayedDbProvider (DB-first, RPC fallback) - If catchup → pure RPC path (safe, no stale-state crash) - Expected: 90%+ reduction in RPC calls during normal operation
- **feat: live wallet counter + line graph on dashboard** (`0dbd578`, xrpl-validator)
