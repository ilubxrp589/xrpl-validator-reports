### Other engineering changes

- **feat: add Domain field to validator manifest** (`206da73`, xrpl-validator)
  Include 'halcyon-names.io' (configurable via XRPL_DOMAIN env var) in the validator manifest as sfDomain (type=7, field=7). This enables XRP Live and other network tools to display the domain association.
- **feat: proper master/signing key separation in validator manifest** (`dc3ebee`, xrpl-validator)
  Derive both Ed25519 (master) and Secp256k1 (signing) keypairs from the same seed. The manifest now correctly maps master → signing with separate signatures from each key.
- **fix: Ed25519 master signature signs raw data, not pre-hashed** (`5e3b356`, xrpl-validator)
  Ed25519 does internal SHA-512 hashing — passing SHA512Half to it produces a double-hashed signature that peers reject. Now correctly: - Secp256k1 (signing key): signs SHA512Half(MAN\0 || manifest) - Ed25519 (master key): signs raw (MAN\0 || manifest) bytes
